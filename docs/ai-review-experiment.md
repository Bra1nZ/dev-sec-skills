# Field report: ensemble AI review of production-critical code

**Кратко (RU).** Ночной прогон четырёхслойного конвейера (статический анализ →
два независимых LLM-ревьюера → формальные модели) на 7 продукционных кодовых
базах критического системного ПО (C/C++, включая kernel-space, и Python)
дал **39 подтверждённых вручную по исходнику дефектов, из них ~12 высокого
класса влияния**. Ни один статический анализатор их полного списка не выдавал;
существенная часть не была видна ни одному слою по отдельности. Отчёт
агрегированный: конкретные уязвимости и их источники не раскрываются.

**Summary (EN).** An overnight run of a four-layer review pipeline (static
analysis → two independent LLM reviewers → formal models) across 7 production
codebases of critical system software (C/C++, including kernel-space, and
Python) produced **39 manually verified real defects, ~12 of high-impact
class**. No single static analyzer surfaced the full list; a material share
was invisible to every individual layer. This is an aggregate report:
specific findings and their origins are withheld.

## 1. Что делалось

Каждая кодовая база прогонялась через четыре независимых слоя:

| Слой | Инструмент | Покрытие |
| --- | --- | --- |
| 1. Статический анализ | cppcheck 2.10 | полное, автоматическое |
| 2. Дифф-ревью порциями | pr-agent (chunked review, GLM-5.3 через LiteLLM-хаб) | порции ≤140 КБ |
| 3. Полное MVP-покрытие | собственный ревьюер (`tools/ai_review.py`), порции ≤50 КБ | честное полное |
| 4. Формальные модели | собственный C-конвейер (`tools/c_items.py`, `tools/model_*.py`) | операции/охраны/функции |

Масштаб прогона: ~107 порционных прогонов слоя 2, ~38 прогонов слоя 3,
~1100 инференс-вызовов, ~26 часов машинного времени, 5 модельных флотов.

## 2. Агрегированный результат

- **39 реальных дефектов**, каждый подтверждён чтением исходника с точностью
  до строки (ни один не принят «со слов модели»).
- **~12 — высокого класса влияния** (нарушение авторизации, отказ в
  обслуживании на уровне ядра, молчаливая деградация криптографии,
  утечки секретов, выход за границы буфера).
- **Ни один дефект не подтверждён как удалённая unauthenticated RCE-цепочка** —
  граница честности прогона: гипотезы атак строились, но не эксплуатировались.
- Ложные срабатывания каждого слоя документированы и отделены от
  подтверждённых находок.

## 3. Главные уроки (инструментальные)

1. **Слепые зоны статического анализатора и LLM-ревьюера перекрываются.**
   Был дефект, который cppcheck пропустил (ложное срабатывание рядом «убило»
   доверие к зоне), а LLM-ревьюер — потому что файл был вырезан при сжатии
   диффа. Нашёл его только слой полного покрытия. Это главный аргумент за
   конвейер из независимых слоёв, а не за «один лучший сканер».
2. **LLM-ревьюер сжимает дифф ДО нарезки на чанки.** Замер по секциям
   coverage: порция 140 КБ теряет ~25% содержимого до того, как модель её
   увидит. «Полное покрытие» даёт только нарезка малыми порциями (≤50 КБ).
3. **Пересечение находок двух LLM-движков ≈ ноль** (измерено ранее на
   эталонных сценариях, см. `spec/ai-review/README.md`): движки находят
   разные классы дефектов, ансамбль обязателен.
4. **Масштабная кривая дифф-ревью**: до ~140 КБ на порцию — стабильно;
   единичный дифф в мегабайты — стабильный отказ движка без ретрая.
5. **Формальный слой работает как карта покрытия**, а не как ищейка:
   тысячи извлечённых операций и охран показывают, какие зоны вообще не
   дошли до ревью, и отрыв контрактов от кода (спеки ссылаются на
   несуществующие поля) — сам по себе диагностический сигнал.

## 4. Честные ограничения

- Две самые крупные базы покрыты только слоями 1, 4 и мега-прогоном слоя 3:
  полный порционный прогон не влез в ночной бюджет (зафиксировано как
  ограничение, не как результат).
- Часть находок среднего класса ожидает финального triage.
- Эксплуатация (PoC) не выполнялась: задача прогона — показать дефектность,
  а не доказуемость атаки.

## 5. Статус

Конвейер воспроизводим: движки слоя 2–4 и гейты (`tools/prepush.sh`,
`make verify-ci`) входят в этот репозиторий. Конкретные находки, имена
проектов и файлов не публикуются — отчёт агрегированный по решению владельцев
кода.
