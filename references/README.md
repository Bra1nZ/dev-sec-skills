# References

Shared reference material for the skills in this repository.

- [`standards-map.md`](standards-map.md) — crosswalk between skill rules,
  Russian FSTEC/GOST requirements, and international analogues. A mapping, not
  a certification.
- [`field-notes.md`](field-notes.md) — design rationale and lessons from the
  standards.
- [`standards/SOURCES.md`](standards/SOURCES.md) — where each downloaded
  standard came from, its license, and its SHA-256.
- `standards/downloaded/` — local copies of freely available standards. Check
  the license before redistributing.

The skills themselves do not require these files to operate. They are here so
a team can connect the discipline to its existing evidence and compliance
work without turning the skill into a standard-specific checklist.
